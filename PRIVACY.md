# LithePage 隐私政策 / Privacy Policy

[中文](#中文) · [English](#english)

## 中文

**生效日期：2026-08-19**

LithePage 的单一用途，是在用户浏览超长学术 HTML 页面时，在本机分析页面结构并应用可撤销的屏幕外渲染优化。

### 本机处理的数据

扩展会在当前网页内临时读取文档结构、文字长度、元素尺寸和当前网站主机名，用于判断页面是否为可安全优化的长篇文章、选择正文块、显示当前页状态，以及读取用户的按网站偏好。

网页内容、论文标题和完整网址不会发送给开发者或任何第三方。LithePage 没有广告、分析服务、账户系统、远程代码或外部网络请求。

LithePage 本身不调用翻译服务。用户选择的浏览器自带网页翻译属于浏览器的独立功能，并受相应浏览器提供方的隐私政策约束。

### 本地保存的数据

浏览器本地扩展存储仅保存：

- 全局及高级功能开关；
- 用户主动选择的按网站偏好及对应主机名。

LithePage 不保存论文正文、论文标题、搜索内容、密码、Cookie 或完整浏览历史。用户可在扩展设置中清除全部按网站偏好；清除扩展数据或卸载扩展也会删除这些设置。

### 数据使用限制

LithePage 不出售、共享或转移用户数据，不将数据用于广告、画像、信用评估或与上述单一用途无关的任何目的。对用户数据的使用仅限于提供明确说明的渲染优化功能，并遵守所发布扩展商店适用的用户数据政策。

### 权限

普通 HTTP/HTTPS 页面访问用于覆盖未知出版社、学会网站、学校代理地址和新模板，并仅在符合条件的长篇文章上应用 CSS。`storage` 权限用于保存上述本地开关与按网站偏好。扩展不请求 Cookie、历史记录、网络拦截或下载权限。

### 联系与更新

支持与隐私问题可通过 [LithePage GitHub Issues](https://github.com/staywithGOD/LithePage/issues) 提交。正式商店发布时，本政策还需托管到公开可访问的 HTTPS 地址。若隐私实践发生实质变化，应更新生效日期和商店披露；LithePage 不会通过静默更新扩大数据用途。

## English

**Effective date: August 19, 2026**

LithePage has one purpose: to analyze page structure on the user's device and apply reversible off-screen rendering optimizations while the user views long academic HTML pages.

### Data processed on the device

Within the current webpage, the extension temporarily reads document structure, text length, element dimensions, and the current site's hostname. This information is used to determine whether the page is a long-form article that can be optimized safely, select article blocks, show the current page status, and apply the user's site preference.

LithePage does not send webpage content, article titles, or full URLs to the developer or any third party. LithePage has no advertising, analytics, account system, remote code, or external network requests.

LithePage itself does not call a translation service. Any built-in page translation selected by the user is a separate browser feature and is governed by the applicable browser provider's privacy policy.

### Data stored locally

Browser-local extension storage contains only:

- global and advanced feature controls;
- site preferences explicitly selected by the user and their corresponding hostnames.

LithePage does not store article text, article titles, search content, passwords, cookies, or complete browsing history. Users can clear all site preferences from the extension settings. Clearing extension data or uninstalling the extension also deletes these settings.

### Limits on data use

LithePage does not sell, share, or transfer user data. It does not use data for advertising, profiling, credit assessment, or any purpose unrelated to the single purpose described above. Data is used only to provide the disclosed rendering-optimization functionality and in accordance with the user-data policies of each extension store where LithePage is published.

### Permissions

Access to ordinary HTTP/HTTPS pages allows LithePage to cover unknown publishers, society websites, institutional proxy addresses, and new templates, and to apply CSS only to qualifying long-form articles. The `storage` permission saves the local controls and site preferences described above. The extension does not request cookie, browsing-history, network-interception, or download permissions.

### Contact and updates

Support and privacy questions can be submitted through [LithePage GitHub Issues](https://github.com/staywithGOD/LithePage/issues). Before a store release, this policy must also be hosted at a publicly accessible HTTPS URL. If privacy practices change materially, the effective date and store disclosures must be updated. LithePage will not expand its use of data through a silent update.
