# LithePage Security Policy / 安全政策

语言 / Language: [中文](#中文) · [English](#english)

<a id="中文"></a>
## 中文

### 支持版本

安全修复目前只面向最新的 LithePage 2.x 主线。

### 报告安全漏洞

请优先使用 GitHub 仓库的 **Security → Report a vulnerability** 私密报告入口。不要在公开 Issue 中发布可利用细节、用户数据、Cookie、令牌或机构凭据。

报告应尽量包含受影响版本、浏览器版本、最小复现步骤、影响范围及建议缓解方法。一般兼容性或布局问题请使用 [GitHub Issues](https://github.com/staywithGOD/LithePage/issues)。

LithePage 不包含远程服务。安全审查重点包括页面 DOM 权限边界、远程代码禁令、消息协议校验、站点偏好存储及恢复行为。

<a id="english"></a>
## English

### Supported versions

Security fixes currently target only the latest LithePage 2.x release line.

### Reporting a vulnerability

Please use the repository's private **Security → Report a vulnerability** form whenever possible. Do not publish exploitable details, user data, cookies, tokens, or institutional credentials in a public issue.

Include the affected LithePage version, browser version, minimal reproduction steps, impact, and any suggested mitigation when available. Use [GitHub Issues](https://github.com/staywithGOD/LithePage/issues) for ordinary compatibility or layout problems.

LithePage has no remote service. Security review therefore focuses on page-DOM permission boundaries, the prohibition on remote code, message-protocol validation, site-preference storage, and restoration behavior.
