- `screenshot-1280x800.png`: feature screenshot using synthetic academic content and the real LithePage popup interface;
- `promo-small-440x280.png`: small promotional tile for the Chrome Web Store;
- `promo-marquee-1400x560.png`: optional marquee promotional image;

- `EDGE_LISTING_ZH.md` / `EDGE_LISTING_EN.md`: Microsoft Edge Add-ons listing copy; and
- `EDGE_PUBLISHING.md`: Edge submission guidance and validation boundaries.
