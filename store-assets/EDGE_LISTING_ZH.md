# Microsoft Edge Add-ons 文案（中文）

## 名称

LithePage

## 简短说明

自动识别超长学术 HTML 页面并延后屏幕外渲染；翻译仍由 Microsoft Edge 自带网页翻译完成。

## 详细说明

LithePage 为超长学术 HTML 页面提供保守的本地渲染优化。它结合论文元数据、正文结构、文字长度和页面高度判断是否启用；只有找到足够多的安全正文块时，才使用 Chromium 的 `content-visibility` 延后屏幕外内容渲染。

它不是翻译器。网页翻译仍由 Microsoft Edge 自带翻译完成。LithePage 的目标是减少长论文在翻译和滚动过程中可能产生的额外布局、绘制与合成负担，而不是改变翻译内容或翻译服务。

主要功能：

- 自动识别超长学术 HTML 页面；
- 不依赖固定期刊或出版社名单；
- 适配常见 section 正文、多层正文包装和高置信度超长参考文献结构；
- 显示当前页状态、优化块数、文本覆盖率、检测耗时和参考条目数；
- 支持当前页临时关闭及按网站自动判断、总是尝试或不启用；
- 对延迟加载全文进行有界重试，成功后立即停止观察；
- 打印时自动恢复完整渲染。

兼容性说明：LithePage 按页面结构工作，而不是按域名工作。具体页面能否启用取决于正文长度、DOM 结构及交互组件。PDF、iframe 阅读器、canvas 阅读器、Shadow DOM 内全文、分页或高度交互式全文页面不受支持。

效果与限制：不同网站、文章长度、电脑配置和 Edge 版本的效果会有差异。LithePage 不能保证消除所有 CPU 占用、卡顿或滚动跳动。首次在新平台使用时，请抽查文章和参考文献的开头、中部与结尾；如有异常，将当前网站设为“不在本站开启”，刷新后再翻译。

隐私：所有检测均在本机完成。LithePage 不包含广告、分析服务、远程代码或开发者服务器通信，也不会上传或保存论文正文。浏览器本地扩展存储仅保存开关和用户主动设置的按网站偏好。
